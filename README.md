# grade-analyzer

Why I built this:
I built this project to practice python fundamentals and apply programming to a problem related to everyday school life.
I wanted to create something practical while improving my understanding of variables, loops, functions, and user input.

Features:
Enter student grades - Calculate the average score - Handle multiple grades

How it works:
The program receives grades from the user and processes them using basic python operations. It then: 
1) Collects the entered grades
2) Calculates the average
3) Displays the result in a simple report.

What I learned:
Variables And Data Types - Lists - User Input - Loops - Functions - Basic Calculations
